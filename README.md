# Визуализация 3D-фигур в OpenGL

Репозиторий содержит два классических примера создания приложений трёхмерной графики с использованием OpenGL и MFC в среде Visual Studio. В проекте Cube реализован вращающийся куб с разноцветными гранями, что позволяет наглядно изучить основы построения трёхмерных объектов, работу с матрицами проекции и моделирования, а также механизмы поворота с помощью клавиатуры и таймера. Проект Torus демонстрирует процедурную генерацию геометрии тора с детализированным управлением угловыми шагами, визуализацией вершин в цветовой модели RGB и использованием полос треугольников для оптимизации рендеринга. Оба приложения поддерживают автоматическую подстройку области вывода под размеры окна.

| Клавиша | Действие |
|---------|----------|
| ← | Поворот влево (уменьшение angleY) |
| → | Поворот вправо (увеличение angleY) |
| ↓ | Поворот вниз (увеличение angleX) |
| ↑ | Поворот вверх (уменьшение angleX) |
| P | Пауза/Остановка авто-вращения (KillTimer) |
| S | Старт/Возобновление авто-вращения (SetTimer) |

- Авто-вращение по таймеру: `angleX += 1; angleY += 1;`
- Шаг ручного поворота стрелками: `±3 градуса`
